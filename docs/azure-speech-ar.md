# الصوت العربي للفيديوهات (Azure AI Speech)

الفيديو يُقرأ مشهدًا مشهدًا بصوت عربي، ويبقى كل مشهد على الشاشة بقدر مدة قراءته، فيصير النص المكتوب ترجمة
متزامنة مع الصوت. الموسيقى (إن وُجدت) تنخفض تلقائيًا تحت الصوت.

## التكلفة
الفئة المجانية **F0**: نصف مليون حرف شهريًا للأصوات العصبية (Neural). الفيديو الواحد نحو 100–200 حرف،
أي آلاف الفيديوهات شهريًا مجانًا. والصوت يُحفظ على جهازك، فإعادة توليد نفس الفيديو لا تستهلك أحرفًا.

## إن ظهر لك "Welcome to Azure! Don't have a subscription?"
يعني أن الحساب/الدليل الذي دخلت به لا يملك اشتراك Azure (كثيرًا ما يحدث عند الدخول بدليل جهة عمل مثل
`MAARIF`). الحل أحد هذين:
- **اشتراك شخصي (الأسهل):** في نافذة خاصة افتح https://azure.microsoft.com/free بحسابك الشخصي واضغط
  **Start free**: تحقق بالهاتف والبطاقة (لا خصم على الفئة F0). أو من نفس الصفحة اضغط **Start** تحت
  "Start with an Azure free trial".
- إن كان لديك اشتراك في دليل آخر: الترس ⚙️ أعلى البوابة ← **Directories + subscriptions** ← بدّل إلى الدليل الشخصي
  (Default Directory).
- **اشتراك جهة العمل:** يتطلب أن يضيفك مسؤول Azure في المؤسسة إلى اشتراك قائم.

## الخطوات (مرة واحدة)
1. أنشئ حساب Azure مجانيًا: https://azure.microsoft.com/free (قد يطلب بطاقة للتحقق فقط؛ الفئة F0 لا تُحاسَب).
2. من https://portal.azure.com ابحث عن **Speech service** ثم **Create**:
   - Resource group: أنشئ واحدة جديدة (مثل `marketing-os`).
   - Region: أي منطقة قريبة متاحة (مثل `West Europe`).
   - Name: أي اسم.
   - Pricing tier: **Free F0** (المسموح به واحد لكل اشتراك).
   - ثم **Review + create** ← **Create**.
3. افتح المورد ← **Keys and Endpoint**: انسخ **KEY 1** واسم **Location/Region** (مثل `westeurope`).
4. في مجلد المشروع شغّل **`set-azure.bat`** والصق:
   - `AZURE_SPEECH_KEY`: المفتاح (لا يظهر أثناء اللصق، وهذا طبيعي).
   - `AZURE_SPEECH_REGION`: المنطقة كما تظهر (مثل `westeurope`) بأحرف صغيرة وبلا مسافات.
   - `TTS_VOICE`: اضغط Enter لإبقاء الافتراضي، أو اكتب اسم صوت من الجدول.
5. أعد تشغيل الخادم (`start.bat`). في صفحة الحملة يظهر: «صوت الفيديو: ar-SA-HamedNeural».
6. في أي منشور فيديو اضغط **إعادة التصميم**، فيُولَّد الفيديو بالصوت.

## الأصوات العربية المقترحة
| الصوت | الدولة | النوع |
|---|---|---|
| `ar-SA-HamedNeural` (الافتراضي) | السعودية | رجل |
| `ar-SA-ZariyahNeural` | السعودية | امرأة |
| `ar-AE-HamdanNeural` / `ar-AE-FatimaNeural` | الإمارات | رجل / امرأة |
| `ar-KW-FahedNeural` / `ar-KW-NouraNeural` | الكويت | رجل / امرأة |
| `ar-QA-MoazNeural` / `ar-QA-AmalNeural` | قطر | رجل / امرأة |

**ملاحظة صريحة:** هذه أصوات بلكنة البلد لكنها تقرأ النص كما هو مكتوب؛ الكلمات العامية الخليجية تُقرأ
غالبًا بشكل مفهوم لكنه ليس لهجة عامية طبيعية 100%. لسرعة القراءة: `TTS_RATE=+10%` في `.env`.

## الأخطاء المتوقعة (تظهر على المنشور)
- **401/403**: المفتاح أو المنطقة غير صحيحة؛ أعد تشغيل `set-azure.bat`.
- **429**: تجاوز حد مؤقت؛ أعد المحاولة بعد دقيقة.
- لإيقاف الصوت: احذف `AZURE_SPEECH_KEY` من `.env` وأعد تشغيل الخادم.
