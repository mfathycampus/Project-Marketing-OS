# ربط فيسبوك وإنستغرام (وضع التطوير، بدون مراجعة Meta)

يعمل مع الصفحات والحسابات التي **تديرها أنت** (أو من أضفتهم بدور في التطبيق). لا يحتاج App Review.
> ملاحظة: كُتبت الخطوات من معرفتي بواجهة Meta، وقد تختلف الأسماء قليلًا. إن اختلف شيء فأرسل لقطة شاشة.

## 1) المتطلبات
- صفحة فيسبوك تديرها.
- (لإنستغرام) حساب **احترافي** (Business أو Creator) **مربوط بتلك الصفحة** (من إعدادات الصفحة ← الحسابات المرتبطة).

## 2) إنشاء التطبيق
1. افتح https://developers.facebook.com ← **My Apps** ← **Create App**.
2. اختر نوع **Business** (أو "Other" ثم Business). سمِّه مثلًا `Marketing OS`.
3. أبقِ التطبيق في وضع **Development** (لا تحوّله إلى Live).
4. من **App settings ← Basic** انسخ **App ID** و**App Secret** إلى `.env`:
   ```
   META_APP_ID=...
   META_APP_SECRET=...
   ```
5. أضف المنتج **Facebook Login** (أو **Facebook Login for Business**) ثم في إعداداته أضف في **Valid OAuth Redirect URIs**:
   `http://localhost:8000/api/v1/meta/callback`
   - إن استخدم تطبيقك **Facebook Login for Business** فأنشئ **Configuration** يتضمن الصلاحيات أدناه، وضع معرّفه في `META_CONFIG_ID`.
6. الصلاحيات المطلوبة: `pages_show_list` و`pages_read_engagement` و`pages_manage_posts` و`instagram_basic` و`instagram_content_publish`.

## 3) إنستغرام يحتاج رابطًا عامًا للصورة
إنستغرام يجلب الصورة من رابط عام (JPEG)، والخادم على جهازك غير ظاهر لهم. أثناء التجربة أنشئ نفقًا مؤقتًا:
```
cloudflared tunnel --url http://localhost:8000
```
سيعطيك رابطًا مثل `https://xxxx.trycloudflare.com`. ضعه في `.env`:
```
PUBLIC_BASE_URL=https://xxxx.trycloudflare.com
```
(فيسبوك لا يحتاج هذا: تُرفع الصورة مباشرة.) تنبيه: مع النفق تصبح صور المنشورات متاحة لمن يعرف رابطها.

## 4) الربط من الواجهة
أعد تشغيل الخادم، ثم **النشر ← ربط فيسبوك وإنستغرام**، سجّل الدخول بحسابك (مدير التطبيق)، وامنح الصلاحيات، واختر الصفحة.
بعد ذلك تُنشر المنشورات المجدولة على المنصات المتصلة تلقائيًا في موعدها، والباقي يبقى للنشر اليدوي.

## ملاحظات
- المنشور الأول: جرّبه على صفحة اختبار أولًا.
- قياسات إنستغرام: صور المنشور العادي بنسبة بين 4:5 و1.91:1. قالب `announcement_story` (9:16) يُرفض كمنشور.
- التوكنات تُحفظ مشفّرة. إن انتهى الربط تظهر "انتهى الربط" في الواجهة فأعد الربط.
